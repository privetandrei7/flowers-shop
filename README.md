# Lumière Flowers

Современный интернет-магазин цветов с доставкой. Интерфейс вдохновлён привычной структурой крупных украинских flower-delivery сервисов, но использует собственный бренд, тексты и дизайн.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Стек

- Next.js 15
- React 19
- TypeScript
- CSS

Изображения в демо загружаются с Unsplash.
